# TaskFlow

A React project management app with boards, tasks, teams, and comments.

## Features

- Boards overview with search, status filtering, pagination, and board creation
- Kanban-style board detail view with column-based task movement
- Task detail pages with comments, labels, due dates, and assignment
- Teams page with member management
- Authentication with signup/login and role-based access (admin vs member)
- Notifications page
- Dark mode
- Accessible, responsive layout
- Unit tests with Vitest and Testing Library

## Getting started

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```

## Linting

```bash
npx eslint src
```

## Tech stack

React 18, React Router, Vite, Vitest.
